# Football SQL Analysis ⚽

This project analyzes football players' performance and salaries using SQL Server.

## Tables Used:
- Player_Info
- Player_Stats
- Teams
- Salary

## Key Features:
- Identify top scorers per club
- Compare player data across tables
- Detect unmatched players across sources
- Calculate total team salary

## Sample Queries:
- Top 5 teams by points and their top scorers
- Players missing in one or more tables
- Highest paid players per club

## Tools:
- SQL Server
- Git & GitHub

> ⚠️ **Note:** The dataset used in this project is not 100% complete. It was designed for learning and practice purposes, and may include missing or unmatched records across tables.
